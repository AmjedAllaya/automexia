# First alpha branding approval

The project owner authorized distribution of the existing owner-supplied
Automexia artwork for `0.0.1-alpha` on 2026-10-12, as part of the request to
complete the first Windows, macOS and Linux release and its branding evidence.
The source image and its SHA-256 remain recorded in `ASSET-MANIFEST.toml`.

The release verifies that source digest, all eight PNG dimensions, and the
Windows ICO and macOS ICNS container bounds. Native package tests verify the
shipped platform metadata and icons. The release manifest records asset hashes.

This is approval for the first alpha. It is not an independent rights opinion
or a claim that editable vector sources and all stable-release variants exist.
The stable `[release]` approval and rights-review fields remain unchanged.
