Add the independent, disabled-by-default Google Cloud M10 source adapter:
bounded named public configurations, exact per-command gcloud configuration,
user and opaque federation login intents, public project/IAM observation,
scope-bound nonactivated IAP/OS Login planning, and an M11-only private
`KUBECONFIG` GKE intent. No gcloud process, network, credential database, IAP
session, GKE cluster, or user kubeconfig is accessed by this source slice.
