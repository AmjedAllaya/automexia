# Pane and customization shortcuts

Windows/Linux/BSD now use Alt+J to clone a right pane and Alt+Shift+J
to create a fresh right pane, leaving Alt+E/R to shells and external overlays.
macOS keeps its Command pane shortcuts. Saved UI mappings survive newly added
defaults; explicit config/profile conflicts still receive validation.

Add direct Workflow & Output, Terminal Appearance, Theme Gallery, Profiles and
Restore Previous Session shortcuts using Ctrl+Shift+F1/F2/F3/F5/F12 respectively
(Cmd+Shift on macOS). The existing actions, mode guards, shortcut editor,
configuration precedence and recovery checks remain authoritative. Regression
tests cover real platform defaults, collisions, exact modifiers, modes, disabled
splits, user overrides, reset, compatibility profiles and effective menu labels.
