### Added

- Added bounded mouse-wheel and precision-trackpad scrolling to overflowing
  command-palette results, with direction-aware fractional accumulation and
  exact top/bottom clamping plus physical-to-logical HiDPI normalization.
- Added a persistent branded vertical overflow indicator that brightens during
  scrolling while remaining subdued and discoverable at rest.

### Fixed

- Kept command-palette wheel events isolated from pane focus, terminal
  scrollback, mouse reporting, and PTY input.
- Reclamped the visible result window after query, keyboard, gesture, and
  responsive-size changes so the selected action remains visible without blank
  trailing rows.

### Testing

- Added real event-owner and palette-state regressions for wheel/trackpad
  direction, fractional input, boundaries, malformed and over-limit deltas,
  modal priority, short/empty lists, resize, query, keyboard interaction, and
  persistent indicator state.
- Extended the native Windows WGPU/CPU workflow to inject real wheel messages,
  verify `0 -> 3 -> 0` palette movement with no terminal or PTY side effects,
  and retain inspected frame and resource-report evidence.
