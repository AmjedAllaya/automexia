# Changed

- Align Windows, Linux, BSD, and macOS default keyboard shortcuts with
  Ghostty's pinned defaults for every currently supported Automexia action.
- Move pane-local tabs, session cloning, and link hints to collision-free
  Automexia extension chords while returning bare `Ctrl+R` and `Ctrl+D` to the
  shell.
- Add runtime configuration reload and cross-platform close-window actions,
  command-palette shortcut parity, collision regression tests, and a complete
  unsupported-action register.
