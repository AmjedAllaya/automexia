# Changed

- Restore Automexia's original platform shortcuts after user evaluation:
  `Ctrl+T`/`Ctrl+Shift+T` for window/pane tabs, `Ctrl+Shift+R/D` for fresh
  splits, and bare `Ctrl+R/D` for independent session clones.
- Preserve history-search and EOF access through explicit
  `Ctrl+Alt+R`/`Ctrl+Alt+D` PTY passthroughs, and keep user overrides
  authoritative.
- Move Ghostty compatibility back to a future explicit, versioned opt-in
  profile rather than making its partial mapping the implicit default.
- Add runtime configuration reload and cross-platform close-window actions,
  command-palette shortcut parity, classic mapping regression tests, and a
  documented compatibility roadmap.
