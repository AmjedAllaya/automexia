# Changed

- Reduce the default desktop title bar from 64 to 48 logical pixels and the
  default maximum tab width from 240 to 200 logical pixels, with proportionate
  compact and minimal viewport densities.
- Keep window and title-bar actions on accessible hit targets while reducing
  their visible plates, glyphs, typography, spacing, and secondary tab rail so
  the terminal gains working space without compromising pointer accuracy.
