# Added

- Add compact Last-command actions to the command palette: copy command, copy
  output, select output, reinsert command, and jump to start. Actions read the
  current grid/history using stable completion identities and reject expired
  boundaries, changed terminal owners, and stale integration generations.
- Reinsertion uses the existing paste transaction without submitting Enter and
  requires an empty integrated prompt. Ambiguous input, concealed text, and
  oversized ranges are refused; no second output buffer or permanent cards are
  introduced.
