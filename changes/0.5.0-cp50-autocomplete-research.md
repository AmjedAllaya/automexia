# CP5.0 native autocomplete research

- Completed the seven-shell native API/version matrix, bounded replacement-only
  editor-state prototype, and machine contract without enabling a runtime
  suggestion surface.
- Added a standalone locked 32/128/512-candidate matcher benchmark covering
  Unicode, combining text, long common prefixes, and stale generations.
- Retained CP1 as the complete native completion solution, rejected a runtime
  matcher dependency on current evidence, and deferred CP5.1 pending a separate
  accepted bridge ADR and native feasibility proof.
- Recorded exact local Windows/PowerShell/CMD/WSL evidence, privacy and resource
  deltas, dependency/licensing/security review, external gates, reproduction,
  and rollback. No user configuration or migration is required.
