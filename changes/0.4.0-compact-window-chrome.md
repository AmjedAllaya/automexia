### Changed

- Reduced the comfortable top shelf from 48 to 42 logical pixels and its total
  terminal-grid reservation from 56 to 46 pixels, with matching compact and
  minimal reservations.
- Tightened the application mark, tab padding, action spacing, typography, and
  default maximum tab width so the chrome uses less horizontal and vertical
  space while keeping profile labels readable.
- Reduced caption cards to 30 logical pixels while preserving separate
  40-pixel interaction targets, native window behavior, DPI invariance, and
  same-control release cancellation.

### Accessibility

- Kept new-tab, command-center, and caption targets at 40 logical pixels across
  every density; exact geometry tests prevent visual compactness from shrinking
  the pointer contract.

### Testing

- Added chrome-specific density-boundary, independent hit/draw/no-PTY-input,
  full-shelf pixel, native-renderer, resource, cleanup, and external-evidence
  requirements to the canonical feature reinforcement contract.
- Added mutation coverage that rejects removal of the exact compact geometry,
  target-size, backend, and default-tab-cap scenarios.
