# Customize command dates, times and results

Command timestamps now offers date formats, 12/24-hour clocks, precision,
weekday/time-zone labels, independent date/time/result positions, order and
separators. Status, exit code and duration have independent visibility controls.
Text size, bold, individual colors and label background opacity share the live
preview and terminal implementation. Narrow command-information rows wrap while
native terminal content, metadata and output/status highlighting stay unchanged.

Version 8 preferences import version 7 only when both current snapshots are
absent, preserving predecessor files for rollback. Reset and Restore saved keep
the existing confirmation workflow.
