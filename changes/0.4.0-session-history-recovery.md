# Smarter session recovery and bounded display history

Recovery keeps the latest 10,000 lines per terminal within workspace resource
limits, preserving text styling and Unicode without rerunning saved commands.
Smart startup prompts distinguish useful work from idle or brief sessions; the
menu can restore a previous session in additional windows at any time.

Checkpoints use local-user encryption. Successful recovery consumes the old
candidate only after a new checkpoint is written. Failed or cancelled recovery
remains retryable; meaningful later sessions replace stale candidates. Saves
coalesce, unchanged content avoids rewrites, and abandoned staging files are
cleaned without touching unrelated files. New configuration controls prompting,
history capture and existing per-profile exclusions.
