# M2 guarded native exact-spawn seam

- Add an absolute-path-only executable guard with opaque native file identity
  and redacted debug output. Windows denies write/delete sharing until process
  creation completes; Unix opens the canonical executable without following a
  final symlink.
- Add an exact PTY creation path that never searches PATH or invokes a shell.
  Windows supplies an explicit CreateProcessW application name, an exact
  application-owned environment, suspended start, and a kill-on-close Job
  Object before resuming the child. Supported Unix targets execute the guarded
  descriptor directly; macOS uses the guarded /dev/fd descriptor route.
- Close Windows process and thread handles deterministically and wait for any
  exit callback before releasing callback state.
- Add native Windows regressions for replacement resistance, exact environment
  isolation, child exit, repeated ConPTY lifecycle cleanup, and a macOS
  cross-check. This seam is not yet connected to the production capability
  broker or Connection Hub, and it does not activate managed SSH.
