# Generic inline-table reconstruction and diagnostics

Preserve blank soft-wrap segments in bounded display serialization without an
unused clipboard allocation. Add conservative schema-aware sparse-row admission,
explicit capture/fallback diagnostics, bounded model attempts, and coherent
surface publication. Add initial-width, chunking, mapping, resource and native
transport regression tests, retaining existing model and renderer tests.

No command-specific schemas, extra workers, dependencies, or guessed hard-line
joins are introduced. Native and performance evidence must be collected on the
target build; see [verification and limits](../docs/INLINE-TABLE-PIPELINE.md).
