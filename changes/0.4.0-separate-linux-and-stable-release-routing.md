# Separate Linux and stable release routing

- Exclude `release/linux/` from the stable-release authorization selector. Linux
  merges previously started that unrelated job and failed its `release/X.Y.Z`
  branch check, despite ordinary CI already separating both channels.
- Keep the stable review, signature and artifact gates unchanged for stable
  branches. The Linux owner-only lane retains its own complete quality gates.
- Add the failing selector reproduction and mutation tests for removal,
  inversion and unconditional replacement. Hosted post-merge evidence must
  confirm stable jobs skip while the Linux release workflow runs.
