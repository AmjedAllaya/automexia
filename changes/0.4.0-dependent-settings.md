# Contextual customization controls

- Hide controls that cannot affect a disabled or hidden option, including date/time
  formatting, table borders and banding, output styles, tag sources, bold font
  weight and extension options. Preserve saved values and their sources.
- Keep enabling controls and independent command-result options available. Remove
  hidden controls from search, focus, accessibility and preview editing; cancel
  unfinished editors when their control disappears.
- Add catalog/view regressions, repeated native Windows interactions and separate
  projection and refresh/layout/paint benchmarks. No preference migration is needed.
