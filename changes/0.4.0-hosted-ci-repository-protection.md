### Security

- Add a versioned, mutation-tested GitHub repository-protection contract with
  exact required checks, SHA-pinned Action policy, read-only workflow tokens,
  fail-closed rulesets, CODEOWNERS validation, hosted-run freshness/exact-head
  proof, authenticated audit, and bounded idempotent application.
- Enable all currently available remote safeguards: squash-only merging,
  source-branch cleanup, update-branch support, web DCO signoff, selected
  SHA-pinned Actions, Dependabot alerts/security updates, and immutable future
  releases. Plan, billing, reviewer-capacity, private-reporting, and secret-
  scanning prerequisites remain explicit release blockers.
