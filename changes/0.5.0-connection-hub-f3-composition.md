Features

- Added application-owned explicit OpenSSH inventory scans that compose bounded
  public D4 records and revisioned favorites, tags, and recency into the
  renderer-neutral Connection Hub catalog.
- Added generation supersession, cancellation, redacted stale health with
  last-known-good retention, and truthful Windows/macOS/Linux setup guidance.

Security

- Opening or searching the Hub still performs no scan, process, network,
  authentication, credential, listener, or PTY operation; scanning requires an
  exact user-provided D4 grant and connection actions remain disabled.
