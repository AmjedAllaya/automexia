# Keep command completion badges separate after resize

- Normalize command-result projections in the core renderer so one stable
  result identity and one display row produce at most one badge.
- Prefer the preceding command's truthful output boundary when the same prompt
  row also owns a newer completed command, preventing datetime and duration
  labels from being drawn over each other.
- Add a raw OSC 133 regression that alternates narrow/wide reflow and navigates
  backward and forward through several commands, plus randomized ordering and
  duplicate-metadata coverage.
- Extend the native Windows test snapshot to expose every command badge draw
  rectangle and reject duplicate identities or intersecting labels after
  resize, navigation, and size restoration.
- Reserve one shared prompt-row region for completion labels, expose optional
  prompt-context rectangles, and reject cross-owner intersections. Controlled
  frames now freeze duration as well as datetime for exact pixel comparison.
- Add a combined 256-command reflow, navigation, and visible-snapshot
  benchmark, and reinforce the repository assurance policy and contributor
  workflow for row-anchored terminal chrome.
- Publish native state checkpoints only after their matching frame presents,
  and require retained Windows captures to hold foreground focus, reject native
  dialog occlusion, cover the complete opaque client area, hold deterministic
  unsent editor input, and stabilize across two exact full-frame pixel digests.
- Include the physical framebuffer extent in CPU frame identity and cache a
  frame only after successful presentation, so content-preserving resizes paint
  every newly exposed row instead of waiting for later terminal input.
- Put ordinary Windows ConPTY sessions in kill-on-close Job Objects and
  broadcast idempotent shutdown to every pane, tab, parked topology, and window
  before joins. Native stress now verifies exact temporary-fixture descendants
  exit within a six-second many-session ceiling.
- Restore the canonical Ghostty G0/G5/G6 status anchors and mutation-protect
  them so the complete architecture self-check remains deterministic.
- Restore the capability-free Connection Hub F2/D5.0 documentation anchor and
  mutation-protect it after the complete QA profile exposed the omission.

Native Linux/macOS frames, assistive-technology sessions, and independently
