# Added

- Add nine information-tag shapes alongside the existing hexagonal chips and
  legacy styles, with matching joints, adjustable spacing and separate end caps
  for wrapped rows and split groups.
- Use the same shape geometry in the customization preview and terminal, with
  pointer selection that respects arrow tips and curved cutouts.
- Store new shape choices in private preference schema 6, importing earlier
  choices without changing older snapshots or the user's configuration file.

# Fixed

- Preserve polygon edges and cutouts on the CPU renderer, including individual
  triangles and shared translucent edges, in both terminal and modal drawing.
