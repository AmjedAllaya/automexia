---
category: Changed
summary: Reduced local and hosted build critical paths while preserving cold release packages and every quality gate.
---

Contributor readiness no longer repeats an all-target/all-feature Cargo check
immediately before warning-denied Clippy compiles the same graph. GitHub quality
jobs use a reviewed, versioned compiler cache and share their lockfile-bound
Cargo source cache with native package jobs. Native x64 and Arm64 release
packages remain cache-free exact-source builds, now run beside quality and join
it before rehearsal or publication. Architecture-matched nFPM archives are
checksum verified instead of compiled from source on every runner.
