Security

Hardened protected releases with final-artifact allowlisting, exact Windows
publisher and timestamp validation, controlled Defender scanning, inside-out
macOS hardened-runtime signing/notarization, final-package SBOMs, checksums, and
provenance/SBOM attestations. Isolated executable signing inputs, exact portable
archive/version contracts, final-package GPU/PTY/WSL smoke, and evidence binding to
the approved publisher and exact scanned package hashes prevent unsigned or stale intermediates
from being mistaken for release artifacts. Added a safe false-positive response
that never disables endpoint protection or installs blanket exclusions.

Windows packages now sign every PowerShell/format resource before packaging and
verify all embedded signatures. SBOMs include the tagged Cargo lock graph and
must agree semantically across SPDX/CycloneDX. Stable publication requires a
byte-identical two-cold-build Linux check, repository immutable releases, a new
tag release, and non-overwriting asset upload.
