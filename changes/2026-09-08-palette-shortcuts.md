# Clearer and complete command shortcuts

Palette shortcut chips show keys without implementation-source badges. Classic
defaults now include Quit (Ctrl+Shift+Q on Windows/Linux), backward pane Find
(Alt+Shift+B), Clear Screen and History (Ctrl+Alt+K; Cmd+Alt+K on macOS), and
Linux fullscreen (F11). Escape remains cancel/back, not Quit.

Explicit unbinds and compatibility profiles remain authoritative. Palette-only
commands show Enter for selected-row activation without creating a global key.
Default-table, override, collision, bounded reload, geometry and controlled CPU
glyph-pixel tests cover the change; native desktop and AT evidence is separate.
