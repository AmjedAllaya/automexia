Changed

- Added validated local, remote, and dynamic SSH tunnel descriptors with exact
  endpoints, loopback defaults, endpoint-bound review fingerprints, OpenSSH
  listener ownership, and bounded session/generation lifecycle state.
- Added a configuration-free exact OpenSSH tunnel grammar using typed
  `-L`/`-R`/`-D` arguments while preserving existing no-tunnel argv and
  rejecting config-dependent routes.
- Added compact icon/color/text tunnel review and accessibility state; remote,
  non-loopback, and production tunnels require a fresh Allow-once decision.

Security

- Kept managed SSH activation false, all forwarding off unless explicitly
  present in a reviewed typed tunnel plan, and agent/X11/command/multiplex/TUN
  forwarding disabled.
- Added independent exact-argv revalidation, stale-scope and terminal-reversal
  rejection, collision-domain checks, route-close cleanup, and synthetic
  release-evidence denial.

Testing

- Ratcheted the immutable session-launch contract to schema 5 while preserving
  schemas 1-4 and added hostile, lifecycle, UI, decision, and deterministic
  1/10/50 cleanup coverage.
- Added a bounded redacted 23-scenario native OpenSSH evidence validator and a
  safe read-only prerequisite probe. Real Windows/macOS/Linux OpenSSH,
  resource, manual-SSH, enable/disable/uninstall, and accessibility evidence
  remains an external release gate.
