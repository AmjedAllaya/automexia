# Customize inline table borders, colors and stripes

Inline tables now offers solid, dashed, dotted, double or hidden borders,
border thickness, independent frame/row/column/header separators, bold headers,
and alternating rows, columns or checkerboard backgrounds. Header, body and
alternate cells have independent text and background colors, with opacity for
backgrounds and borders. The live sample and terminal share appearance logic;
wrapped rows stay in the same stripe, while status colors, explicit terminal
colors and selections retain priority. Appearance choices survive disabling the
feature and are included in its existing reset and restore flow.

User preference version 7 imports version 6 only when both current snapshots
are absent. Older snapshots remain unchanged for rollback.
