### Changed

- Removed the shared outline, surface, and shadow around the custom minimize,
  maximize/restore, and close controls so each action reads as its own card.
- Removed the short decorative underline beneath every caption control while
  preserving individual brand-colored glyphs and card state feedback.
- Preserved right-edge hit targets, same-control release activation, and native
  window behavior.

### Performance

- Removed three decorative rounded-rectangle draw submissions per rendered
  frame without adding state, allocation, or another renderer owner.
- Removed three additional underline draw submissions per rendered frame; the
  recordable draw interface remains monomorphized and allocation-free in
  production.
