# Refine terminal chrome and table edges

Keep the existing dark layout with more balanced tab/control spacing, softly
rounded glass-like surfaces and restrained upper highlights. Footer spacing and
separators are quieter, and default table rules use neutral blue-grey. Explicit
user colors, opacity, tag shapes and terminal text are preserved. The finish
uses existing bounded CPU/GPU primitives with no blur pass or animation.

Native checks use the undecorated Kubernetes namespace, wait for command
completion before checking pane isolation, and compare fully contained image
pixels at fractional positions without relaxing rendering tolerances.
