# Harden M6 workspace review and release assurance

- Reject duplicate JSON member names at every nesting level across connection,
  workspace, private-library, import, and recipe-context ingress.
- Revalidate reviewed recipe and broadcast contents, reject clock reversal and
  deadline overflow, and close every pending broadcast target on expiry.
- Restore a workspace from only its referenced profiles, including when the
  library contains more than 128 unrelated profiles.
- Require explicit recovery for a legacy previous generation and add a dedicated
  M6 semantic checker, mutation suite, fuzz/benchmark coverage, and S1 matrix.
- Reject overlong Windows verification targets before MSVC linking and support
  a short absolute `AUTOMEXIA_VERIFY_TARGET_ROOT` on the intended drive.
- Managed execution remains disabled pending protected D3/M5 and controlled
  native release evidence.
