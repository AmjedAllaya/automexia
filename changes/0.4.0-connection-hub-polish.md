# Changed

- Polished the Connection Hub with the shared Automexia palette, a smaller
  first-run card, concise setup copy, visible mnemonic keycaps, and less
  repeated status/path detail.
- Exposed the existing scope-safe `C`, `W`, and `P` section navigation
  with visible keycaps and added `F` exact-file selection. Pointer and
  keyboard file selection now share one native picker path and remain isolated
  from terminal input.
- Added a native Windows regression that drives `W -> P -> C` under both WGPU
  and CPU rendering, captures the composited frames, and proves dismissal
  preserves the active terminal route, cursor, scroll position, and current
  line.
