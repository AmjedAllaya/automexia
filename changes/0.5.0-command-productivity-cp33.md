# CP3.3 trusted native imports and workspace task bridges

- Added bounded, capability-free dry-run parsers for explicitly supplied
  PowerShell CSV, Bash/Zsh aliases, Fish abbreviations, CMD/DOSKEY macros, and
  Git aliases. Unsafe shell constructs, controls, likely secrets, duplicate
  names, machine paths, and unsupported alias kinds fail closed.
- Added explicit selected native import with portable ID rename, conflict
  preview, replacement consent, revision compare-and-swap, one atomic
  transaction, portable export compatibility, and no changes to native sources.
- Added exact insert-only just, Task, and mise workspace task bridges in
  .automexia/actions.toml, with no recipe parsing, task discovery/listing,
  provider process, network access, credential read, or task execution.
- Added private path-free digest/revision trust receipts, dry-run trust and
  revocation, conflict/rename/removal lifecycle, read-only no-side-effect lookup,
  bounded ancestor/cache reconciliation, and insertion-time authorization
  rechecks.
- Added CLI commands, hostile/security/lifecycle tests, a schema-1 contract and
  mutation suite, aggregate policy/CI/xtask gates, nightly fuzzing, parser/trust
  benchmarks, ADR 0021, and synchronized roadmap, architecture, security,
  testing, CLI, feature, audit, and release documentation.
