Added

- Add an explicit `+ssh` wrapper using system OpenSSH and bundled Bash, Zsh,
  Fish and PowerShell adapters, preserving native profiles and SSH arguments.
- Keep remote prompt/status and context display separate from local paths,
  providers, pane cloning and file actions. Nested sessions restore their own
  metadata and command state on return.
- Add generated-shell, parser, renderer and isolated SSH regression coverage.
- Offer opt-in temporary helper upload for automatic remote Git, Kubernetes,
  Docker, Terraform and cloud context, with bounded discovery and stale-result
  isolation. No permanent remote installation or profile changes are required.
- Refresh displayed metadata when an invalid replacement is rejected, without
  waiting for command output or a window resize.
