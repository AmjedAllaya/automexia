# CP5.1-CP5.6 authenticated suggestion-bridge proposal

- Added proposed ADR 0025 for an optional, native-editor-owned, peer-checked
  local suggestion bridge. Runtime implementation and activation remain
  forbidden until the exact proposal is explicitly accepted.
- Added a versioned machine contract for CP5-T17 through CP5-T22 covering
  endpoint/replay, buffer/history privacy, stale replacement, candidate
  spoofing, input/occlusion, and resource amplification with fixed limits,
  shell fallbacks, lifecycle, rollback, residual risk, and external gates.
- Added 17 hostile mutation/document tests and registered them in repository
  validation, full QA, and pull-request CI.
- Added the detailed CP5.1-CP5.6 implementation audit and synchronized the
  architecture, threat model, compatibility, assurance, testing, indexes, and
  roadmap status to “Partially done (proposal only).”
- No runtime dependency, endpoint, worker, helper, shell hook, profile change,
  shortcut, command-buffer capture, suggestion UI, migration, or user-visible
  behavior was added. CP1 remains the complete default and fallback.
