### Fixed

- Pane and local-tab removal no longer waits on native PTY shutdown. One bounded
  application cleanup service retains join ownership and existing process-tree
  safeguards. Rapid close/open cycles cannot create an unlimited worker backlog.
- Recent close acknowledgements are bounded even when a worker emits no exit event.

### Improved

- A fixed Back button remains available while scrolling or searching a category,
  and returns from font/extension lists. Existing keyboard Back remains supported.
- Palette matching and drawing avoid repeated filtering and unnecessary
  allocations while preserving Unicode matching and result ordering.
- Shortcut dispatch normalizes each event once and copies only matched actions;
  existing platform defaults, modifiers and user overrides are unchanged.
- Added real ConPTY close/child-exit, native thread-destructor, capacity, repeated
  cleanup, header geometry and search-equivalence regressions. Native desktop
  visual and assistive-technology evidence remains a separate validation gate.
