### Changed

Font-size shortcuts now update every open pane and window, and Automexia
restores the selected font size and light/dark appearance on the next launch.
`Ctrl`/`Cmd`+`0` clears the saved font override and returns to the current
`config.toml` size.

The application stores only these runtime-editable values in a private,
versioned, 16 KiB-bounded file below the product `state/` directory. Writes are
coalesced on one background worker, locked across application instances,
replaced through a same-directory staged file, and recover one previous valid
snapshot. The store contains no terminal content, history, paths, credentials,
provider state, or session topology, and never rewrites `config.toml`.
