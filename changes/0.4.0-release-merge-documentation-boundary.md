# Linux release candidate reconciliation

- Preserve the current runtime, lifecycle, and assurance fixes while resolving
  the Linux release candidate against the current main branch.
- Limit public documentation to current implementation, limitations, and
  release evidence; remove prospective feature summaries and design recipes.
- Reinforce documentation checks with mutations covering renamed public pages,
  changelog entries, duplicate status rows, unresolved merge markers, and
  redacted disclosure diagnostics.
- Release signing credentials are configured; the guarded publication result
  remains required before claiming a public package. ADR 0040 records the
  subsequently accepted owner-only Linux authorization policy.

The reconciled tree passed the Windows full-QA run: 41 required checks,
2,308 workspace tests and 610 Python mutation tests, plus formatting,
warnings-as-errors Clippy, doctests, shell integration, resize/session-clone
checks, concurrency models and dependency policy. Eight tests in each main
suite were explicitly skipped; controlled native visual/accessibility evidence,
coverage, long-running benchmarks and release publication remain separate
gates. Secret and machine-local-identifier scans found no issues in the
reviewed working tree. These local results are not public package evidence.
