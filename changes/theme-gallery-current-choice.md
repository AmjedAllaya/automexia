# Make the applied theme clear in the gallery

- Keep the applied theme in its normal library position without a duplicate
  saved-choice row; identify it with a full-card highlight and Current theme badge.
- Keep temporary keyboard preview focus separate from the applied palette and
  preserve a saved palette when its source file changes or disappears.
- Cover inventory refresh/import, configuration inheritance, stale pointer
  presses, accessibility labels and contrast/layout across built-in themes and scales.
- Reserve room for readable preview captions so compact sample text cannot overlap them.
