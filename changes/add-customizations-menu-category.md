The command palette opens Customizations as a feature list rather than one long
control list. Information tags, output highlighting, inline tables, command
timestamps, theme, font size, and installed extension features each open a
separate page in the same native settings sheet. Each page reuses the existing
preference store and controls; search is scoped to the current page, and Back
restores the feature list with its search and focus intact. Information tags
have their own visibility switch, independent of installed extension controls.
