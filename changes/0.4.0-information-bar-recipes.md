### Added

- Offer twelve information-bar format presets and a bounded custom recipe with
  independently selectable text and icon sources, slot order, colors, and
  display-only text. Each slot has a separate page under Information tags.
- Let users adjust the gap between information tags from 0% to 300% of the
  selected format's spacing; older saved recipes retain the existing 100% gap.
- Show a live sample in each customization page, with a side-by-side layout on
  wide windows and a compact stacked layout on narrow windows.
- Let number controls accept a typed or pasted value in their center field,
  while keeping the minus and plus buttons for incremental changes.
- Share information-tag shape geometry and width-aware layout between the
  terminal and its preview; preserve visible outlines in plain styling.
- Keep shared feature controls in the main list and select individual tags,
  role colors, and output status colors through a mouse- and keyboard-operated preview edit mode.
  Current and valid draft colors remain visible together while editing.
- Keep one feature-organized Customizations entry in the command palette, with
  distinct menu icons; the existing Settings shortcut opens that same editor.
- Keep recipe choices in version-4 user preferences, migrating older snapshots
  without changing them. Installed extension feature controls remain scoped to
  the installed package and disappear from Customizations when it is removed.
