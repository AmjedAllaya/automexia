# Command completion datetime

- Capture one validated terminal-owned local completion datetime for every
  accepted desktop OSC 133 completion, including boundary-only stock CMD.
- Carry the Unix-millisecond identity and local calendar fields through prompt
  repaint, row reuse, reflow, viewport overflow, source eviction and the
  following-prompt result boundary without storing command or output text.
- Show `YYYY-MM-DD HH:MM:SS` beside status and duration when space permits;
  drop duration first, then use `MM-DD HH:MM` before the existing status-only
  fallback. Missing or invalid clock state never fabricates a timestamp.
- Extend deterministic renderer, real shell lifecycle, native Windows WGPU/CPU,
  assurance-checker and manual matrices with timestamp identity, clipping,
  responsive, timezone, no-PTY and no-history-mutation requirements.
