# Customize fonts and terminal colors

Replace the Font size customization page with Fonts: installed family, weights,
bold/italic styles, spacing, ligatures, rendering options and terminal colors,
with a live preview and saved preferences. Font loading runs in the background;
failed or cancelled changes keep the current font active.

Version 9 imports existing preferences without changing older rollback files.
