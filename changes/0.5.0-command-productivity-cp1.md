Add bounded, native-shell command completion for PowerShell, Bash, Zsh, and
Fish, with truthful CMD fallback, read-only health, explicit provider refresh,
native-definition precedence, digest verification, and exact removal.
Provider generation is isolated in POSIX process groups or Windows Job Objects
so deadlines and output ceilings also terminate spawned descendants.
Adapters reject substituted parent links/reparse points, Windows refresh rejects
implicit batch launchers, and native registration p95 is enforced at 50 ms.
Follow-up hardening makes doctor validate digest, metadata, provenance, consent,
and directory safety; terminates inherited-pipe descendants after an early
provider-leader exit; revalidates provider executable identity; rejects relative
state roots; aligns macOS installation with the canonical Application Support
path; repairs stale managed profile blocks; and preflights exact uninstall
targets before mutation.
The completed audit hardening now validates the destination before launch,
clears provider environments to a secret-free allowlist, filters relative and
remote Windows executable paths, rejects bidi/control diagnostics, enforces the
4 KiB root ceiling in every adapter, and uses a two-digest atomic transition so
an interrupted refresh preserves a verifiable last-known-good completion
artifact.
PowerShell install and completion integrity checks use the platform cryptography
API directly, avoiding unreliable module auto-loading on the shell startup and
clean-install paths.
