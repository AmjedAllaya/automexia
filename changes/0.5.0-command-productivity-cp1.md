implicit batch launchers, and native registration p95 is enforced at 50 ms.

and directory safety; terminates inherited-pipe descendants after an early
provider-leader exit; revalidates provider executable identity; rejects relative
state roots; aligns macOS installation with the canonical Application Support
path; repairs stale managed profile blocks; and preflights exact uninstall
targets before mutation.
