Completed the accepted CP5 native-editor bridge at its disabled source boundary.
The package now contains an inert persistent helper target, authenticated
application replies, a bounded screen-publication mailbox and route exchange,
and session-only PowerShell, Bash, Zsh, and Fish request/response adapters that
revalidate current editor state and replace once without Enter or PTY input.

Added exact response limits and hostile-status rejection, real local Windows
PowerShell and WSL Bash/Zsh/Fish bridge tests, policy mutations, fuzz coverage,
and OS-specific hosted test steps. Failure-first native cases now enforce strict
UTF-8 boundary classes, C0/C1, U+061C, and bidi rejection in every adapter while preserving valid 2/3/4-byte replacement. Fish uses fixed
inherited descriptors, a 2,176-byte `/dev/fd/4` read cap, and a streaming
4-KiB-line/512-item completion bound instead of materializing all completions.

The application package now explicitly retains `automexia` as Cargo's default
run target, so adding the inert helper cannot break existing `cargo run`,
packaging-manifest, or generated-keybinding workflows.

Preview and stable activation remain disabled. A reviewed launcher, signed and
attested artifact, WSL host relay, live screen composition, public controls,
successful three-OS endpoint/shell runs, accessibility/GPU/resource evidence,
package rollback, and longitudinal soak evidence remain CP5.6 release gates.
