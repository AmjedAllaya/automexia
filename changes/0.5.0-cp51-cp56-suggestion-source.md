Accepted ADR 0025 and added the disabled CP5 source boundary: strict authenticated
editor request/submission/replacement models; restrictive Windows/Unix endpoint
adapters; bounded local sources, ranking, cache, cancellation and lifecycle;
pane-owned accessible UI projection/controller/renderer; fuzz, benchmarks and
mutation policy; and inert version/collision-guarded PowerShell, Bash, Zsh and
Fish request scaffolds.

No user-facing autocomplete preview is activated. The signed helper, native
response/replacement adapters, WSL relay, Fish Unicode bridge, public settings
and shortcuts, native three-OS/accessibility/package/rollback/resource evidence,
and 30-day preview baseline remain release gates. CP1/native completion remains
the default and fallback.
