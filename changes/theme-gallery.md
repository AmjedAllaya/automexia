# Theme gallery with instant preview

Add five built-in palettes, including a light theme, with arrow-key preview,
Apply and Escape restoration. Customize creates a local copy using the existing
color editor; validated TOML import/export and Use configuration keep ownership
clear. Theme files reuse the configuration parser, run on a bounded worker and
persist through the version-10 preference overlay. Dialog surfaces follow the
palette while preserving contrast and independent semantic color settings.
