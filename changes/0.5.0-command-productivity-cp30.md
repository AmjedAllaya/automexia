Implemented the CP3.0 capability-free shell projection compiler for PowerShell,
Bash, Zsh, Fish, and CMD. The compiler enforces portable eligibility and typed
argument policies, consumes bounded complete collision/completion/tool
observations, preserves native ownership unless exact fingerprinted user consent
is supplied, and emits deterministic digest-verified rollback metadata with
activation disabled.

A follow-up audit made the boundary fail closed against valid-but-unrelated
source digests, incomplete tool observations, forged same-action ownership, and
existing completion collisions when completion generation is disabled. Projected
bindings carry deterministic owner fingerprints; decisions retain missing or
unsupported tool health for the UI; and structured owner/tool mutations are
verified. The CI workflow now runs the alias and CP3.0 mutation suites as separate
valid YAML steps.

Added thirteen focused serializer/native-capture/tamper/hostile/boundary tests, a
nightly all-five-shell libFuzzer target, a 256-binding Criterion target, an exact
source allowlist, and a schema-1 mutation-tested integrity/publication/rollback
contract. Managed profile publication, persistent alias activation, packs, and
trusted task bridges remain CP3.1-CP3.3.
