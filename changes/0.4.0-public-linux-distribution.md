### Release engineering

- Added a create-once Linux Early Access lane that builds and tests native x64
  and Arm64 DEB, RPM, and portable packages, signs an exact public bundle, and
  publishes it through a repository-scoped GitHub App only after draft checks.
- Added immutable GitHub release verification, a source-commit and manifest-
  digest website activation handoff, public install/remove/release guidance, and
  mutation coverage for package, checksum, symbol, scope, state, and workflow
  weakening failures.
- Added a credential-free native package rehearsal, current GitHub API pinning,
  signed release and per-asset attestation verification, plus mutations that
  reject secret exposure or publication-gate weakening. Publication now audits
  the live passive-repository settings and both no-bypass rulesets before it can
  create a tag or draft.
- Closed a local/hosted workflow-lint parity gap by checksum-pinning ShellCheck
  0.11.0 beside actionlint, passing its path explicitly, and adding mutations
  that reject scanner removal or version drift. The same fix removed all
  actionlint/ShellCheck findings from the Linux and stable release workflows.
- Created and protected the passive public `automexia-releases` binary archive;
  added active default-branch and `v*` tag rulesets, public metadata and support
  policy, and kept Actions/issues/Projects/wiki disabled. No application package
  or website download was activated by this change.
