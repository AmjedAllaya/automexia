# Owner-authorized Linux release

- Apply the explicitly accepted solo-maintainer policy only to Linux Early
  Access: the pinned human owner may author and merge the release PR without a
  second-person approval. Validate original and rerun actors, merged-event
  state, source/base/head repository, branch and exact current-main identity.
- Bound event bytes, depth and node count; reject malformed, duplicate,
  non-finite or type-confused data with redacted diagnostics.
- Preserve credential-free manual rehearsal, full native package/quality gates,
  Minisign verification, scoped GitHub App authority, public-archive governance,
  immutable publication and every asset attestation check.
- Add owner/event/CLI regression cases and workflow mutations for deleted,
  duplicated, reordered, ignored or substituted authorization. Keep the separate
  stable-release review contract unchanged. Real signed publication remains
  external evidence until the guarded workflow succeeds.
