Add the independent, disabled-by-default Azure M9 source adapter: bounded public
subscription metadata, exact tenant-scoped Azure CLI broker/browser/device and account
review requests, an AAD-only nonactivated Bastion plan, and an opaque
private-transient AKS credential intent for later M11 ingestion. No Azure
process, network, authentication, token cache, Bastion session, AKS cluster, or
user kubeconfig is accessed by this source slice.
