- Add review-only M6 typed recipe runs, bounded retry/cancellation/generation
  lifecycle, no-hooks recovery intent, and narrow POSIX-sh/PowerShell remote
  initialization without arbitrary command strings or implicit Enter.

  migration preview, reviewed entity/import/export previews, exact dependent
  profile/recipe/workspace revisions and fingerprints, approval invalidation,
  CAS/recovery, fresh import IDs, and redacted topology-only workspace transfer.
- Add bounded declarative multi-window/pane workspace clone, rebind, and restore
  plans that never persist or resume PTYs, credentials, tunnels, automatic
  reconnect, or interrupted actions.
- Add explicitly armed, production-confirmed broadcast review with exact transient
  command/targets, per-target isolation, cancellation, digest-only audit, and
  redundant semantic UI state.
- Accept ADR 0023 and add the public preview-first `automexia workspaces` manager,
  immutable Hub worker publication, and a responsive Workspaces catalog/restore
  review with pointer/keyboard/accessibility contracts and stale-review rejection.
  Product execution remains disabled pending existing D3/M5 protected/native
  managed-SSH gates.
