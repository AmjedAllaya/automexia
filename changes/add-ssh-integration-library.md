# Non-executing SSH planning ownership

Add a private first-party planning library without enabling SSH execution or
changing native OpenSSH review authority. Register its dependencies and static
boundaries in canonical validation, reuse workspace encoding/property tools and
existing application benchmarks, and retain coupled assurance ownership.

The experimental Bash candidate preserves setup permissions and native prompt
hooks, declines conflicting state, and emits scoped metadata on terminal stderr.
Controlling-PTY tests consume the actual compiled generator in the Unix shell
verification scope. Native SSH/UI evidence remains external; no activation or
full remote prompt/status support is claimed.
