### Added

- Show bounded settings declared by an installed, verified package under
  Customizations. Each feature has its own controls; saved choices never grant
  capabilities or run package code. Removing the package removes its controls
  after a successful inventory refresh.

### Reliability and security

- Keep package preference failures separate from core Settings saves. Recheck
  installed content against its receipt on a worker before displaying package
  metadata, and preserve core controls when package inventory is unavailable.
