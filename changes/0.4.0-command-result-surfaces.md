# Make completed command output easier to distinguish

Completed output now receives a visible but restrained success/error-tinted
surface, an adaptive 6-10 pixel visual breathing gutter, an end rule, and a
known-status icon plus duration. The semantic owner applies the same treatment
to every proven result, including listing and non-listing commands, success and
error exits, pipelines, native programs, single- and multiline output,
and deeply wrapped managed input. A newly completed live result lightens once,
holds for the first third of its 540 millisecond cycle, then eases out without
repeating, moving content, or restarting in scrollback.

A follow-up validation incident fixed PowerShell failures that could inherit a
stale successful native-process code. PowerShell result styling now uses its
completed pipeline state, preserves exact native exit values, and leaves user-
owned `LASTEXITCODE` unchanged. The VT now clears stale prompt/result identity
when unrelated output or partial erases reuse a terminal row, while an active
identified prompt repaint claims the row for its current generation. This
prevents an old surface from being selected beneath formatter, full-screen, or
other row-rewriting output.
An identified but blank prompt marker also no longer proves a command row;
output bounds require owned continuation metadata or visible single-row prompt
content, so an unowned following row cannot be highlighted.


Native Windows regression coverage exercises eight PowerShell command shapes,
including exact `ls -ll`, pipeline, stderr exit `7`, and silent completion;
checks interactive CMD neutral grouping; checks real output-glyph pixels; and
directly compares blank surface pixels with the neighboring background on both
WGPU and the CPU fallback. A real Automexia/ConPTY/WSL/Bash matrix covers stdout,
multiline, stderr failure, and silent success. Parser benchmarks measure both
verified-status and boundary-only lifecycles.

The treatment is renderer-only. It does not insert terminal rows, write PTY
input, or change selection, copy, search, history, reflow, and shell ownership.
Integrated PowerShell, Bash, Zsh, and Fish publish complete identified
lifecycles. Integrated CMD closes each result at the next prompt and uses a
neutral surface without inventing status or duration. Silent commands and
unintegrated shells fail closed without painting guessed output.
