# Make completed command output easier to distinguish

Completed output now receives a quiet success/error-tinted surface, slim left
accent, visual breathing gutter, end rule, and the existing icon plus duration.
A newly completed live result lightens once for 180 milliseconds, then settles
without repeating, moving content, or restarting in scrollback.

The treatment is renderer-only. It does not insert terminal rows, write PTY
input, or change selection, copy, search, history, reflow, and shell ownership.
