# Changed

- Move local-tab rails from window-wide chrome into their owning panes, keeping
  sibling pane geometry independent and restoring the rail after tiny resizes.
- Use one DPI-safe pane content rectangle for PTY sizing, terminal rendering,
  image previews, scrollbars, cursor/IME placement, drawing, and pointer hits.
- Keep tab-title reads off the render critical path by falling back to cached
  route identity when a pane's active terminal lock is busy.
- Add deterministic property, HiDPI hit-target, and native resize-snapshot
  regressions for local-tab containment and one-tab restoration.
- Strengthen architecture verification to reject any return of a window-wide
  local-tab reservation or removed global workspace actions.
