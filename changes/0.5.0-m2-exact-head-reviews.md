Security

The protected-path review gate now carries each review's commit identity into
the policy checker and counts an approval only when it matches the exact current
pull-request head. Stale, missing, or malformed commit records fail closed;
author, bot, and case-duplicate exclusions remain enforced. The adapter also
bounds review JSON to 4 MiB/10,000 records and rejects unsafe login/commit forms
before writing the GitHub environment. Managed session launch remains disabled.
