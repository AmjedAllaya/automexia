# M8-M12 cached provider product and private lifecycle

- Add a compact cached-only Providers catalog and detail review for AWS, Azure,
  Google Cloud, Kubernetes, OpenShift, and Teleport in the Connection Hub.
- Keep provider activation fail-closed: the surface starts no login, process,
  network request, browser flow, or PTY and rejects unsupported OpenBao state.
- Require a new capsule identity, session, and monotonic revision for provider
  replacement; revoke and shutdown invalidate transient review ownership.
- Add the application-owned bounded private kubeconfig lifecycle for EKS, AKS,
  GKE, Kubernetes/OpenShift, and Teleport-related output, including validation,
  tamper detection, expiry, revoke, provider/session cleanup, shutdown, and
  repeated full-capacity cleanup.
- Add keyboard, pointer, responsive, accessibility, security, integration, and
  Criterion evidence; real provider tools/accounts/clusters and protected D3
  activation remain release gates, and OpenBao remains blocked on ADR 0024.
