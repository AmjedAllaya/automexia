# Terminal appearance controls

Customizations now separates Workflow & Output from Terminal Appearance. Theme,
Window controls and Fonts move into Terminal Appearance without duplicate pages.
New pages customize header/tabs, footer visibility/status/style, pane spacing and
borders, and window background opacity/blur/padding. Changes use the existing
live settings, color picker and versioned preference store. Hidden footers give
space back to terminal content and hide their dependent controls. Pane restore
and unzoom retain current appearance. Previous preference files remain available
for rollback; no release or native compositor certification is implied.
