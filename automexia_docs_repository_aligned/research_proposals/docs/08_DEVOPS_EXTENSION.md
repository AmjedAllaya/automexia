
# DevOps Direction

Continue wrapping mature official tools rather than rebuilding protocols:

```text
OpenSSH
aws
az
gcloud
kubectl/oc
tsh
Docker/Podman where applicable
```

Process invocation must use existing reviewed broker/owner paths, exact executable identity, sanitized environment, cancellation, and typed outcomes.

Keyboard-first does **not** mean "no connect button."

A renderer-native accessible button is valid when it dispatches the same reviewed semantic plan as:
- keyboard;
- palette;
- menu;
- command.

No UI surface gets separate authority.

Near-term priority is provider/native activation evidence, not redesigning DevOps into a new public extension ecosystem.
