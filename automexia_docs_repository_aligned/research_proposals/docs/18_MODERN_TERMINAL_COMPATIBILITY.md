
# Modern Terminal Compatibility

This is a core product requirement.

Contract order:

```text
protocol/standards documentation
    ↓
Automexia supported contract
    ↓
real application/native fixtures
    ↓
selective Ghostty differential reference
```

Define exact supported versions/modes for:
- VT/xterm behaviors;
- extended keyboard protocols;
- mouse;
- OSC;
- graphics protocols;
- Unicode/grapheme behavior.

Maintain application fixtures with version/platform labels for:
- shells;
- Vim/Neovim;
- tmux;
- fzf;
- less;
- representative TUIs.

Ghostty is one reference, not the oracle.
