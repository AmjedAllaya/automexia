
# Platform Capability Catalogue

**State:** backlog/idea inventory, not an implementation commitment.

Potential capabilities may include:
- persistent sessions;
- semantic command history;
- secure paste/clipboard;
- resource-aware actions;
- offline resource cache;
- file transfer;
- Mosh;
- containers/WSL/devcontainers;
- future database workflows;
- local specialized automation.

Every item needs:
- owner;
- user value;
- threat model;
- dependency cost;
- activation gate;
- native evidence;
- release priority.

Do not let a capability catalogue silently become a roadmap.
