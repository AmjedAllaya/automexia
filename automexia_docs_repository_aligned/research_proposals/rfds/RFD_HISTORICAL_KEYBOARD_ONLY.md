
# Historical Keyboard Only

**Type:** Research/Request-for-Discussion note — not a project ADR
**Repository integration note:** Historical/superseded. Keyboard-first now permits pointer convenience through same semantic actions.

This file preserves proposal reasoning without claiming an ADR number or acceptance status.

---


## Historical decision
The original decision prohibited graphical first-party interaction and allowed only keyboard-controlled text surfaces.

## Supersession
Product requirements were clarified: Automexia intentionally uses small renderer-native overlays such as Connection Hub, Extension List, Quick Actions, confirmation, search, and settings/status surfaces.

The later semantic-overlay direction supersedes this historical keyboard-only idea: Automexia is keyboard-first and keyboard-complete, while pointer controls may invoke the same semantic actions.
