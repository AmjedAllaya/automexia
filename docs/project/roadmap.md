# Project roadmap overview

This page summarizes the public [open-source roadmap](../ROADMAP.md). It does
not expose private advanced or commercial planning and never overrides source,
tests, feature documentation, or release evidence.

## Current work

- stabilize terminal, PTY, renderer, input, resize, and shutdown behavior;
- complete native Windows, Linux, and macOS evidence;
- improve accessibility, configuration recovery, installation, and uninstall;
- preserve shell, search, image, keyboard, and terminal-protocol compatibility;
- complete signed package and public release evidence;
- document current free behavior clearly.

## Status rule

Implemented source remains release-gated until its security, native,
accessibility, performance, resource, packaging, and release evidence passes.
See [Features](../FEATURES.md) and [Readiness](../READINESS-AUDIT.md).

Advanced future and commercial plans are intentionally not summarized here.

## Command productivity

Preserve native editor authority and complete the remaining native and release evidence
for the source-owned completion, insertion, alias, and static-pack boundaries.
Source presence is not an activation or availability claim.
