# CP5.1-CP5.6 accepted source audit

Status: accepted for bounded source implementation; preview and stable release
activation remain disabled. Source implementation is authorized only within the
reviewed capability-free contract.

## Evidence ledger

| Boundary | Source status | Remaining release proof |
|---|---|---|
| Authenticated local bridge | Implemented at the local source boundary | Native peer identity, teardown, replay, and package evidence |
| Framing and identity | Exact schema, size limits, capabilities, route and generation binding | Fuzz, mutation, native transport, and privacy evidence on release artifacts |

## CP5.1

The application owns one authenticated, OS-local, session-scoped endpoint.
Remote transports, terminal-output signalling, grid inference, and
per-keystroke helper processes remain forbidden.

## CP5.2

Frames validate the length prefix before allocation, require exact compatible
schema versions, bind capability and route identities, and reject duplicate,
decreasing, stale, cross-pane, or unknown state before publication.

## CP5.3

Candidate sources are local, bounded, deterministic, cancellation-aware, and
incapable of provider authentication, credential access, recursive discovery,
network access, or action execution while the user types.

## CP5.4

One immutable renderer-neutral snapshot is owned per pane. It is clipped below
modals, dismissed on invalidation or IME start, and cannot capture Enter or
replace native editor submission.

## CP5.5

Native adapters preserve shell editor ownership, revalidate the exact buffer,
cursor, selection, quote context, replacement span, route, and generations,
then replace at most once without Enter. Unsupported shells use CP1/native
fallback.

## CP5.6

Preview stays off by default. Lifecycle ownership includes bounded workers,
latest-generation cancellation, endpoint removal, capability rotation, cache
cleanup, immediate kill switch, disable, uninstall, and CP1 fallback.

## Commit and rollback strategy

Keep the typed contract, transports, sources/ranking, renderer-neutral UI, and
native adapters independently reversible. A failed or missing optional layer
must leave ordinary native completion and terminal I/O intact. Release
activation requires exact native, security, privacy, performance, resource,
visual, accessibility, packaging, and rollback evidence.
