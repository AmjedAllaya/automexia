# CP5.0 native autocomplete research

Status: accepted public source-decision summary. This document does not promise
product availability or disclose private commercial sequencing.

## Evidence ledger

| Area | Current evidence | Public conclusion |
|---|---|---|
| Existing completion | CP1 owns bounded session integration and native fallback | CP1 remains the complete solution for the documented release |
| Native editors | Shell-owned APIs and editor lifecycles differ by shell and version | Any richer source boundary must remain opt-in and adapter-specific |
| Local transport | The reviewed contract permits authenticated OS-local IPC only | No terminal-output protocol, TCP service, or per-keystroke process |
| Release | Source checks do not replace native shell, platform, privacy, accessibility, or package evidence | Preview and stable activation remain gated |

## Shell and version decision matrix

PowerShell 7/PSReadLine, Bash/Readline, Zsh/ZLE, Fish, and supported guest shells
retain command-buffer, cursor, quoting, completion, and insertion ownership.
Windows PowerShell 5.1 and CMD keep their native fallback where the reviewed
adapter contract cannot preserve those boundaries. Exact supported versions are
source-contract data and require native verification before a release claim.

## Matcher comparison

The accepted source contract uses deterministic local ranking: exact prefix,
native rank, word-boundary prefix, case-insensitive prefix, optional decayed
frequency, then bounded fuzzy score. Stable source priority, normalized display,
and request-local candidate identity break ties. Ranking never grants execution,
provider, network, credential, filesystem-crawl, or history-file authority.

## Build, wrap, or adopt decision

Adopt each native editor's public integration mechanism, wrap it with a bounded
session adapter, and build only the capability-free typed protocol, validation,
cancellation, ranking, and renderer-neutral snapshot owned by Automexia. Do not
build a replacement shell editor or completion language.

## Privacy and authority delta

The optional bridge is local, authenticated, session- and pane-bound,
generation-aware, memory-only for command-buffer payloads, metadata-allowlisted
for diagnostics, and incapable of submitting a command. CP1 remains the complete solution
when the bridge is disabled, unavailable, incompatible, or fails validation.

## External evidence

Native peer-identity behavior, installed shell adapters, IME and focus handling,
screen readers, tiny-through-8K layout, performance/resource baselines,
long-duration cleanup, signing, packaging, disable, uninstall, and rollback
must be demonstrated on the exact release artifact. Missing evidence is not a
pass and does not change the default CP1 fallback.
