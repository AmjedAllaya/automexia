## Ownership at a glance

| Area | Owner |
|---|---|
| Command syntax, quoting, history, completion, aliases, pipelines | Your shell |
| Programs, scripts, remote clients, data/media tools | The tool you run |
| Terminal input/output, tabs, panes, search, selection, clipboard | Automexia |
| OpenSSH credentials, agents, host keys, authentication, network | System OpenSSH and the operating system |
| Configuration and themes | Automexia configuration, with user files preserved |
| Optional installed code | Versioned capability contracts enforced by Automexia |
