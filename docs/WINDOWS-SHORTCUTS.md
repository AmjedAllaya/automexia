# Automexia Windows defaults

## Tabs

- Ctrl+Shift+T — new tab
- Ctrl+Shift+W — close active split/tab
- Ctrl+Tab / Ctrl+Shift+Tab — next/previous tab
- Ctrl+PageUp / Ctrl+PageDown — previous/next tab
- Ctrl+1..8 — select tab 1..8
- Ctrl+9 — last tab
- Ctrl+Shift+PageUp / Ctrl+Shift+PageDown — move tab left/right

## Panes

- Ctrl+Shift+R — split right
- Ctrl+Shift+D — split down
- F6 / Shift+F6 — next/previous pane, disabled in alternate-screen/Vi/search modes
- Alt+Shift+Arrow — resize pane

## Application

- Ctrl+Shift+P — command palette
- Ctrl+, — settings
- Ctrl+Shift+N — new window
- F11 or Alt+Enter — fullscreen
- Ctrl+Alt+Space — quake window
- Alt+Shift+T — appearance theme

## Terminal/clipboard

- Ctrl+Shift+C / Ctrl+Shift+V — copy/paste
- Ctrl+Shift+A — select all
- Ctrl+Shift+K — clear scrollback
- Shift+Insert — paste selection
- Ctrl+0 / Ctrl+= / Ctrl++ / Ctrl+- — font size
- Ctrl+Shift+Space — Rio Vi mode
- Ctrl+Shift+F — search; Shift+Enter selects the previous result

Readline/editor conventions such as Ctrl+C, Ctrl+A, Ctrl+W, Ctrl+K, Ctrl+U and Ctrl+T remain unbound by the application.
