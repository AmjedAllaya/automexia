# Automexia Terminal — Linux Early Access

Less friction. More flow. A flexible terminal for focused command-line work.

This prerelease includes DEB, RPM and portable archives for Linux x64 and Arm64.
Download the package matching your architecture from this release's assets,
not GitHub's automatic source-code archives. No Windows, macOS or AppImage
package is included. Website download activation is separate.

Every package is published with an exact SHA-256 manifest, a detached minisign
signature, a public verification key, SPDX and CycloneDX SBOMs, installation and
removal guidance, and third-party notices. The release manifest binds the public
files to the reviewed private-source commit without publishing private source or
debug symbols.

Early Access is not a stable-release guarantee or certification of every Linux
desktop, GPU, shell or assistive technology. Check the guides' version and
evidence scope against your chosen package, and verify before installing.
Published assets are immutable; edited release-page prose and current repository
guides are separate from the signed version-bound documents attached below.
