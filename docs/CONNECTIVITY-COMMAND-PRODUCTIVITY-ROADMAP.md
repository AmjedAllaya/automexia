# Connectivity and command-productivity direction

Status: public summary. Detailed execution sequencing is maintained privately.

## Outcome

Automexia should connect terminal work, remote access, environment context, and
command assistance without hiding native tools or executing suggestions
automatically.

## Current foundation

The repository contains source foundations for typed Quick Actions, completion,
aliases, environment capsules, connection inventory, a read-only Connection
Hub, exact-argument launch review, and provider-neutral adapter boundaries.
Several live and native release gates remain incomplete; consult feature-specific
documentation before treating a source component as supported.

## Public delivery direction

1. Preserve terminal stability and complete release evidence.
2. Finish safe, user-reviewed SSH and remote connection workflows.
3. Activate provider adapters independently with native authentication and
   bounded discovery.
4. Make completion and Quick Actions aware of the selected environment without
   performing provider work on each keystroke.
5. Add diagnostic navigation and situation-aware production guidance after the
   context, authority, and evidence boundaries are proven.
6. Expand organization and third-party integrations only after capability,
   provenance, disable, and uninstall controls are ready.

The exact phase graph, per-provider checklist, internal status ledger, and next
implementation task remain outside the public repository. See the main
[Roadmap](ROADMAP.md), [Command Productivity](COMMAND-PRODUCTIVITY.md), and
[SSH architecture](SSH-DEVOPS-MULTICLOUD-ARCHITECTURE.md).
